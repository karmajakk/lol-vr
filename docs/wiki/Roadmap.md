# Roadmap

These are ideas, not promises.

## Reliability (priority)

- Validate in the headset the detection of game states (dungeon, menus, map, character sheet), performance and comfort.
- Keep windows from going through shelves and other objects.

## Immersion

- Room lighting tied to the dungeon (torches, spells, damage).
- Live-updating map (needs an engine change).
- More objects and variety in the library.

## Easier installation

- Folder picker in the headset, with a check of the game files and a clear message.
- Direct import of the GOG installer.

## Later

- **Dungeon in true 3D**: needs rebuilding the levels from the game data, or building on an open engine if a full remake comes out (fan remakes in Godot exist for both games).
- **Lands of Lore 2**: the engine used here doesn't support it; waiting for an open engine.

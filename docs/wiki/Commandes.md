# Commandes

| Manette | Action |
|---|---|
| Viser + gâchette | Clic gauche (la main qui clique devient le pointeur) |
| Viser + poignée | Clic droit |
| Joystick gauche | Avancer, reculer, pas de côté (une seule direction à la fois) |
| Joystick droit (gauche/droite) | Tourner |
| Joystick droit (haut/bas) | Dans le donjon : personnage suivant / précédent |
| A | Dans le donjon : **attaquer** avec le personnage choisi. Ailleurs : Entrée |
| B | Dans le donjon : ouvrir la **magie** du personnage choisi. Ailleurs : Échap (passer une cinématique) |
| Y | Carte |
| **X** | **Clavier et options** : taper un nom de sauvegarde, son du feu, panneaux, table, ranger |
| Bouton menu (manette gauche) | Menu ScummVM : sauvegarder, charger, quitter |
| Clic du joystick droit | Recentrer l'écran, la pièce et les panneaux devant soi |
| Clic bref du joystick gauche | Changer de décor (bibliothèque → réalité mixte avec cadre → réalité mixte avec moniteur) |
| Clic du joystick gauche maintenu + joystick droit | Haut/bas : taille de l'écran ; gauche/droite : distance |

## Déplacer l'écran et les panneaux

L'écran et le clavier portent une **barrette de laiton** au-dessus d'eux ; les fenêtres du jeu la portent sur le côté, pour ne pas gêner le pointeur entre l'écran et les fenêtres.

1. Visez la barrette (le rayon jaune s'allonge dès que vous quittez l'écran et les panneaux).
2. Serrez la gâchette et gardez-la serrée : l'objet suit votre main.
3. Pendant que vous le tenez, le joystick droit le pousse ou le tire (haut/bas) et le rapetisse ou l'agrandit (gauche/droite).
4. Relâchez pour le poser.

Les positions sont mémorisées d'une fois à l'autre.

## La table

Dans la bibliothèque, la table porte une barrette au-dessus de son plateau. Tenez-la à la gâchette et pointez le plancher : la table glisse là où vous visez. Le joystick droit (gauche/droite) change sa taille. Le bouton « Table » du clavier (X) la retire ou la remet.

## Aide dans le casque

Un panneau résume les manettes et les boutons. Il s'affiche de lui-même au premier lancement ; ensuite, ouvrez le clavier (X) et cliquez « Aide ». Un clic sur le panneau le ferme.

## Agrandir ou réduire

Visez un coin de l'écran ou d'une fenêtre, juste à l'extérieur (sur le cadre, pour l'écran) : une équerre de laiton apparaît. Serrez la gâchette, puis écartez la main pour agrandir ou rapprochez-la pour réduire. La fenêtre change de taille autour de son centre.

## Combat aux boutons

Dans le donjon, un personnage est « choisi » : il est encadré de jaune dans la fenêtre du groupe. **A** le fait attaquer, **B** ouvre sa liste de sorts (on choisit ensuite le sort en le visant). Un coup de joystick droit vers le haut ou le bas passe au personnage suivant ou précédent. Dans les menus, les cinématiques, la carte et la fiche d'un personnage, A et B redeviennent Entrée et Échap ; la touche Échap reste aussi disponible sur le clavier (X).

## Clavier (bouton X)

Un clavier virtuel s'ouvre, utile pour nommer une sauvegarde. Sa première rangée contient les options : Feu (son de la cheminée), Panneaux (interface détachée ou image entière), Table (afficher ou retirer la table de la bibliothèque), Ranger, Fermer. Sous les touches, deux lignes indiquent quelles images personnelles sont affichées.

## Vibrations

Les manettes vibrent quand le groupe frappe ou est blessé, à l'ouverture des portes, aux leviers et aux sorts.

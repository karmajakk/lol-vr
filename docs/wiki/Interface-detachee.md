# Interface détachée

Pendant l'exploration, l'écran ne montre que la **vue du donjon**. Le reste de l'interface du jeu est réparti sur des fenêtres que l'on place où l'on veut :

- le groupe (messages et portraits),
- l'inventaire,
- le parchemin des sorts,
- les commandes (flèches, options, repos),
- la boussole.

Au départ, elles sont toutes dans le plan de l'écran, autour de la vue : le pointeur passe de l'une à l'autre sans décalage, ce qui permet de ramasser un objet au sol et de le déposer dans l'inventaire. Si vous visez juste à côté d'une fenêtre, le pointeur s'accroche à la plus proche.

Elles suivent l'écran quand on le déplace ou qu'on change sa taille. Dans la bibliothèque, elles ne traversent ni le plancher, ni les murs, ni la table (mais elles peuvent encore traverser les étagères et les autres objets).

Dans les cinématiques, les menus, la carte et les scènes qui occupent toute la largeur, l'image entière revient d'elle-même.

Le bouton **Panneaux** du clavier (X) rend l'image entière en permanence ; **Tout ranger** remet les panneaux à leur place d'origine. Pour déplacer une fenêtre, voir [[Commandes]].
